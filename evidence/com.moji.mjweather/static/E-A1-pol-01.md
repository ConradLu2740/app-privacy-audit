## 3. 关键发现

1. **政策整体披露较完整**：OAID/IMEI/MAC/IMSI 等具体字段名直接出现在政策正文，是国内工具类 App 中**披露粒度较细**的一档
2. **第三方 SDK 共享**：
   - **已点名**：推啊（金币中心）、平安好医生（健康功能）
   - **未单独点名**：友盟、个推、穿山甲、字节、高德、百度、腾讯（这些在静态中已确认存在，政策中仅以「数据分析服务商、效果广告服务商」笼统表述）
3. **后台/静默状态收集**：C-05-m 直接写明「后台/静默状态时收集」设备信息，是合规敏感点
4. **剪贴板**：场景明确（首页、卡券识别），与 A2 豆瓣的「仅本地识别不上传」措辞不同
5. **亲子公开信息**：C-11-m 自承「客观的隐私泄露风险」，**披露即合规**写法可作参考

## 4. 局限

- 动态受阻（壳保护 + 真机无 root），无法验证政策中描述的「首页访问剪贴板」「后台静默收集」是否在运行时实际发生
- 流量受阻（首启卡 splash），无法验证广告 SDK / 数据分析服务商是否在 60s 内触发网络请求
- 政策正文抓取自 HTML5 页（移动端版式），桌面网页版可能内容一致但版式不同

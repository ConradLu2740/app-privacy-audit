## 1. 政策关键声明摘录

| 主题 | 政策原文要点 |
|------|-------------|
| 设备标识符 | 明确定义含 Android ID、OAID、GUID；用于「安全运行与分析统计」「个性化广告」 |
| 应用安装信息 | 「我们可能会收集你的应用安装信息，用以判断你的设备是否安装了某个App」（跳转唤起场景） |
| 剪贴板 | 「我们需要使用你的剪切板，我们仅在本地识别剪切板内容，不会将其上传至我们的服务器」 |
| 精确位置 | 仅用于「地点签到」功能，「不会存储或另作他用」 |
| 第三方 SDK | 声明接入第三方 SDK，提供《第三方合作清单》 |
| 个性化广告 | 披露使用 OAID、设备信息、浏览记录等做画像 |
| 数据存储 | 境内存储，不向境外提供 |

## 2. 三列对照（政策 vs 静态 vs 动态/流量）

| 检查项 | 政策声明 | 静态发现 | 动态/流量观测 | 一致性 |
|--------|----------|----------|---------------|--------|
| OAID/设备标识 | 披露（安全+广告） | 自研 `getDeviceId()`；OAID SDK 线索 | 未直接观测（无 root） | **政策已披露** |
| QUERY_ALL_PACKAGES | 披露「应用安装信息」（限跳转场景） | Manifest 声明 | 未观测 | **政策已披露，范围较窄** |
| 剪贴板 | 披露「仅本地识别，不上传」 | `ClipboardManager` 相关代码较多 | 未观测 | **声明明确，待动态验证** |
| 精确定位 | 披露（仅签到） | `ACCESS_FINE_LOCATION` 声明 | 未观测 | **政策限制用途，合理** |
| 第三方 SDK | 披露 + 合作清单 | 友盟/京东/阿里 mtop 等 | 60s 流量仅豆瓣自有域名 | **未触发，可能懒加载** |
| 自研埋点域名 | 未单独列出 | `com.douban.push` deviceId | `amonsul.douban.com` 流量 | **自有域名，政策未单独点名** |

## 3. 关键发现

1. **政策披露较完整**：设备标识、应用安装信息、剪贴板、精确定位均有说明
2. **剪贴板声明「不上传」**：静态代码多但声明仅本地使用——需动态 hook `getPrimaryClip` 验证是否有网络外传
3. **第三方 SDK 在 60s 前台会话未触发**：可能因为未登录、懒加载、或仅特定场景初始化
4. **`amonsul.douban.com`** 为自研埋点，政策未单独点名域名，但整体归入「安全运行与分析统计」

## 4. 局限

- 未登录状态下观测，登录后可能触发更多 SDK
- 无法解密 HTTPS 载荷，无法验证剪贴板内容是否真的未上传
- 政策《第三方合作清单》未单独抓取

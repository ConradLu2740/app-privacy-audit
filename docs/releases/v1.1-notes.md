## v1.1（2026-09-17）

**中文版（主）**

在 v1.0 基础上补齐了流量侧短板，工具链四条线全部可复现：

### 新增
- **静态关键字扫描器** `scripts/static/scan.py`：对 Jadx 反编译产物一键扫描，8 类敏感 API/SDK 指纹（设备标识、定位、剪贴板、应用列表、明文 HTTP、三方 SDK 等）对齐检查清单 S-* 项，词边界匹配防误报，报告只含文件路径与命中数、可直接入库。A1 墨迹 2.7 万文件约 24s 扫完。
- **A1 墨迹天气流量实证**（`E-A1-trf-02`）：首启完成授权后 60 秒观测窗口，535 条连接 / 74 个独立主机。静态发现的第三方 SDK（京东、腾讯 GDT、高德、穿山甲、百度、个推、友盟）**全部在流量层得到实证**；并发现 50 条明文 HTTP 连接集中于自有日志端点（新风险项 F-10）。

### 变化
- DoD 自检 **7/8 → 8/8 全通过**（A1 从「受阻取证」升级为「观测到」类证据）。
- 风险表新增 **F-10：日志端点明文传输**；F-04 第三方 SDK 共享从「未验证」升级为「已观测联网」。
- 检查清单 T-01~T-06 A1 列全部改写；README 双语同步；06 章后续工作勾完 3 项。

### 仍受环境限制（与 v1.0 一致，诚实声明）
- A1/A2 动态 Frida 注入仍受阻：真机无 root，爱加密/网易易盾壳杀进程；需要 root 设备或脱壳环境。
- 流量为连接级元数据，HTTPS 载荷不可见（未登录、无 root 证书信任）。

**English**

On top of v1.0, this release closes the traffic-side gap. All four tool-chain lines are now reproducible:

- **Static keyword scanner** (`scripts/static/scan.py`): one-shot scan of Jadx output across 8 categories (device IDs, location, clipboard, package enumeration, plaintext HTTP, third-party SDK fingerprints) aligned to checklist items S-*; word-boundary matching; reports contain paths and counts only, safe to commit. ~24s for A1's 27k files.
- **A1 Moji Weather traffic evidence** (`E-A1-trf-02`): 60s observed window after first-launch onboarding — 535 connections / 74 unique hosts. Every third-party SDK found statically (JD, Tencent GDT, AMap, Pangle, Baidu, Getui, Umeng) is **now confirmed on the wire**; plus 50 plaintext HTTP connections to first-party log endpoints (new finding F-10).
- DoD self-check **7/8 → 8/8**; new risk finding F-10 (plaintext log endpoints); checklist T-* rows and bilingual README refreshed.

Known limits (unchanged, by design): A1/A2 dynamic injection still blocked by commercial packers on a non-rooted device; traffic evidence is connection-level metadata — HTTPS payloads remain encrypted (unlogged session, no user-CA trust).

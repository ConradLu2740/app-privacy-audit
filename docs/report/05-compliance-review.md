### 政策来源

| 项 | 内容 |
|----|------|
| 标题 | The NewPipe project — Privacy Policy |
| URL | `https://newpipe.net/legal/privacy/` |
| 体例 | GDPR Art.13/14 告知书；侧重官网/博客/Sentry 崩溃上报 |
| 应用内路径 | 未在本轮截取；以官网政策文本为准 |

### 政策条款摘录（C-xx）

| 条款 ID | 原文要点（英译中精简） | 主题 |
|---------|------------------------|------|
| C-01-a | 「aims to provide a private, anonymous experience for using media web services」 | 产品定位 |
| C-02-a | 官网不收集访客个人数据、不装 cookie、不做用户跟踪 | 网站 |
| C-03-a | Web 服务器访问日志会截断 IP（IPv4 去掉后两段等）后保留 | 网站日志 |
| C-04-a | 崩溃时用户**可选择**通过系统邮件发送 JSON 崩溃报告 | App 崩溃上报 |
| C-05-a | JSON 含：邮箱、错误类型、页面 URL、语言、时间、应用名/版本、OS 名称版本 API 级、堆栈；「implemented to not embed any personal data」 | 崩溃字段 |
| C-06-a | 「We will not share any of the data with third parties」 | 第三方共享 |
| C-07-a | Sentry 为**自建**实例；磁盘加密；备份最长约 6 个月 | 存储与安全 |
| C-08-a | 列出 GDPR 查询/更正/删除/限制/撤回同意/异议等权利 | 用户权利 |

### 观测摘要（本轮）

| 观测线 | 结论 | 证据 |
|--------|------|------|
| Manifest 权限 | 无定位/电话状态/通讯录/`QUERY_ALL_PACKAGES`/广告 OAID 簇 | E-A3-sta-01 |
| 动态 Hook（约 30s 剧本） | 未观测到 IMEI/ANDROID_ID/定位/剪贴板读/已安装列表 | E-A3-dyn-02 |
| 流量 | 本轮未做 | — |

### 三列对照（R-xx）

| R-ID | 政策 | 实际行为（证据） | 规则要点 | 一致性 | 风险 |
|------|------|------------------|----------|--------|------|
| R-01 | C-01-a 匿名/隐私优先 | E-A3-sta-01：无定位/电话/通讯录权限；E-A3-dyn-02：窗口内无标识符/定位调用 | 最小必要（若适用中国个保法场景需另核） | **一致** | 低 |
| R-02 | C-04-a/C-05-a 崩溃上报为用户选择、字段透明、尽量不含个人数据 | 本轮未触发崩溃对话框，**未验证**邮件 JSON 路径 | 告知同意、最小必要 | **待核** | 低（设计上偏保守） |
| R-03 | C-06-a 不向第三方共享（项目侧数据） | 静态未见广告/统计 SDK 包名信号（对照 A1/A2） | 第三方共享披露 | **一致（静态支持）** | 低 |
| R-04 | 政策主要描述官网与 Sentry，**未单独列出** App 播放时会请求哪些内容站点 | 动态未覆盖网络目标；流量未做 | 业务必要网络访问的透明度 | **披露不足（文档粒度）** | 低/观察 |
| R-05 | C-08-a 用户权利 | 开源可审计；应用本地数据删除依赖用户卸载/清数据 | 查询删除权 | **部分可核**（非集中式账号体系） | 低 |

### 时序问题

| 场景 | 观察 |
|------|------|
| 同意前是否收集标识符 | 冷启动剧本未观测到标识符 API；政策亦未声称此类收集 |

### A3 小结

- **与 A1/A2 对照：** 权限面、静态 SDK 面、动态观测三者一致，指向「低采集」产品设计，而非仅靠政策承诺。  
- **仍缺：** 流量侧域名清单；崩溃上报实操路径。  
- **风险等级（本项目内部标准）：** 观察/低 — 无高风险观测项。  
- **法规引用：** 本政策以 GDPR 为主；若用中国《个保法》条文做对照，须另开「已核对日期」行，不在本轮编造条号。

## A1 墨迹天气（`com.moji.mjweather` 9.0942.02）

### 政策来源

| 项 | 内容 |
|----|------|
| URL | https://html5.moji.com/tpd/agreement/privacy-zh_CN.html |
| 体例 | 「墨迹天气隐私政策」HTML5 移动页；现行版 |
| 应用内路径 | 因首启受阻未截屏；以官方 HTML5 页为准 |

### 政策条款摘录（C-xx-m）

详见 `evidence/com.moji.mjweather/static/E-A1-pol-01.md` §1。核心要点：

- C-02-m/C-03-m/C-04-m：广告、定位、推送场景下点名收集 IMEI/MEID/IMSI/OAID/Android_ID/MAC/IDFA
- C-05-m：「后台/静默状态时收集」设备信息
- C-07-m：与第三方共享「电话号码、设备MAC地址、唯一设备标识符（...）、位置信息」
- C-08-m/C-09-m：点名「推啊」「平安好医生」两家第三方服务商
- C-12-m：「进入首页后访问您的剪切板，以判断是否有可复制或粘贴的卡券信息」

### 观测摘要（本轮）

| 观测线 | 结论 | 证据 |
|--------|------|------|
| Manifest 权限 | 定位 + 后台定位 + 活动识别 + 相机 + `PACKAGE_USAGE_STATS`（maxSdk 28）+ OAID 厂商簇 | E-A1-sta-01 |
| 静态 SDK | 友盟、个推、穿山甲、高德、百度、腾讯 等；OAID 323 文件命中 | E-A1-sta-01 |
| 动态 Hook | **受阻**（壳杀进程 + 真机无 root） | E-A1-dyn-01/02 |
| 流量 | **完成**（首启 60s：535 连接 / 74 主机 / 50 明文 HTTP，见 E-A1-trf-02） | E-A1-trf-01 · E-A1-trf-02 |

### 三列对照（R-xx）

| R-ID | 政策 | 实际行为（证据） | 规则要点 | 一致性 | 风险 |
|------|------|------------------|----------|--------|------|
| R-10 | C-02-m 定位 + 设备标识 | E-A1-sta-01：定位/OAID 厂商簇声明 | 最小必要 | **政策已披露**（与静态一致） | 中（后台收集） |

| R-16 | C-11-m 亲子公开信息「自承风险」 | E-A1-sta-01：未直接命中亲子业务代码 | 公开信息风险告知 | **披露即合规** | 低 |

### 时序问题

| 场景 | 观察 |
|------|------|
| 同意前是否收集标识符 | 动态受阻，**未验证**；政策声明「您勾选并点击『同意』即视为您接受本隐私政策」 |
| 首次启动是否触发后台静默收集 | 动态受阻，**未验证**；政策 C-05-m 已披露 |

### A1 小结

- **披露质量**：字段粒度比 A2 豆瓣更细（点名 IMEI/MEID/IMSI/OAID），但**第三方 SDK 共享清单**不如 A2 具体（仅点名推啊/平安好医生 2 家）
- **合规敏感点**：后台/静默收集（C-05-m）、广告标识体系庞大（R-11）
- **风险等级（本项目内部标准）：** 中
- **法规引用：** 政策依《个人信息保护法》原则（七原则）；具体条款号本轮不编造，待需要时核对原文

| 项 | 内容 |
|----|------|
| URL | https://www.douban.com/about/privacy |
| 版本 | 2026-07-02 更新 / 2026-07-09 生效 |
| 体例 | 「豆瓣个人信息保护政策」主文 + 《个人信息收集清单》+ 《设备权限说明》+ 《第三方合作清单》三附件 |

### 政策条款摘录（C-xx-d）

详见 `evidence/com.douban.frodo/static/E-A2-pol-01.md` §1。核心要点：

- 设备标识符明确定义：Android ID、OAID、GUID（Android 端）；用途为「安全运行与分析统计」「个性化广告」
- 「应用安装信息」：「用以判断你的设备是否安装了某个App」（跳转唤起场景）
- 「剪贴板」：「我们仅在本地识别剪切板内容，不会将其上传至我们的服务器」
- 「精确位置」：「仅用于地点签到功能，我们不会存储或另作他用」
- 第三方 SDK：接入并提供《第三方合作清单》

### 观测摘要（本轮）

| 观测线 | 结论 | 证据 |
|--------|------|------|
| Manifest 权限 | 定位、相机、录音、`QUERY_ALL_PACKAGES`、`REQUEST_INSTALL_PACKAGES` | E-A2-sta-01 |
| 静态 SDK | 友盟、穿山甲、阿里 mtop、高德、京东、腾讯、厂商推送 等；OAID 143 文件命中 | E-A2-sta-01 |
| 动态 Hook | **受阻**（壳 = 网易易盾 NIS，attach 后自杀） | E-A2-dyn-01/02 |
| 流量 | 60s 前台会话**仅豆瓣自有域名**；未登录 | E-A2-trf-01 |

### 三列对照（R-xx）

| R-ID | 政策 | 实际行为（证据） | 规则要点 | 一致性 | 风险 |
|------|------|------------------|----------|--------|------|
| R-20 | 设备标识符定义 + 用于「安全运行/广告」 | E-A2-sta-01：自研 `com.douban.push` deviceId + OAID SDK 信号 | 字段定义清晰度 | **政策已披露** | 低 |
| R-21 | 「应用安装信息」限跳转唤起 | E-A2-sta-01：`QUERY_ALL_PACKAGES` 已声明 | 最小必要 | **政策已披露，范围较窄** | 低 |
| R-22 | 剪贴板「仅本地识别，不上传」 | E-A2-sta-01：`ClipboardManager` 30 文件；`getPrimaryClip` 6；动态受阻 | 网络外传验证 | **声明明确，待动态验证** | 低 |

| 场景 | 观察 |
|------|------|

- **风险等级（本项目内部标准）：** 低 / 观察
- **法规引用：** 同 A1，本轮不编造条款号

# 01 · 样本清单

## 选样标准

- 应用商店可公开下载，用户量中等以上  
- 至少 1 款隐私政策文本较完整  
- 类型尽量分散（工具 / 内容社交 / 生活服务等）  
- 避免强加固金融类与隐私点不典型的游戏

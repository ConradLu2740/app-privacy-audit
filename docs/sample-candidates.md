# 候选样本调研（待你下载后锁定）

> 状态：**候选，未锁定**。包名/加固情况可能随版本变化，以你实机 `aapt`/商店页为准。  
> 标准见 [report/01-samples.md](report/01-samples.md)：商店可下、有隐私政策、类型分散、避开强加固金融与典型游戏。

## 选样原则（执行版）

| 原则 | 原因 |
|------|------|
| 先 2 款做透，再考虑第 3 款 | 单人时间；深度 > 覆盖面 |
| 至少 1 款「定位为核心功能」 | 动态/流量容易有故事 |
| 避开：银行/支付/强壳金融 | 反编译与 unpinning 成本过高 |
| 避开：微信/QQ/支付宝本体 | 系统级复杂度，不适合第一期 |
| Jadx 能看到 Java 层调用点 | 否则静态线整段作废 |

## 推荐组合（首选）

### A1 · 工具/天气 — 墨迹天气

| 项 | 内容 |
|----|------|
| 建议 ID | **A1** |
| 包名（请核验） | `com.moji.mjweather` |
| 类型 | 天气工具 |
| 为何选 | 定位与功能强相关，易观察「权限—API—上报」；用户量大，场景真实 |
| 预期检查重点 | 精确定位、设备标识、广告/统计 SDK、政策是否写清第三方 |
| 风险/成本 | 可能有加固或多 SDK，静态搜索噪音大；以动态 Hook 兜底 |
| 政策 | 商店页/App 内应有隐私政策入口，锁定时记更新日期 |

### A2 · 内容社区 — 豆瓣

| 项 | 内容 |
|----|------|
| 建议 ID | **A2** |
| 包名（请核验） | `com.douban.frodo` |
| 类型 | 书影音社区 |
| 为何选 | 政策文本通常可读；内容类可对比「浏览 vs 收集」；体量中等偏上 |
| 预期检查重点 | 标识符、剪贴板、已安装应用、第三方内容/广告 SDK、注销入口 |
| 风险/成本 | 组件多，建议只走「冷启动 + 首页浏览」标准剧本 |
| 与 A1 对比价值 | 非定位核心 App，可写「同类标识收集、不同披露」 |

### A3 · 生活/旅行 — 马蜂窝 或 下厨房（二选一，可后置）

| 项 | 马蜂窝 | 下厨房 |

| 包名（请核验） | `com.mafengwo.cn` | `com.xiachufang` |
| 预期 | 位置/行程相关内容，可能更敏感 | 相对轻量，适合时间紧时替换 |
| 建议 | 若 W2–W3 顺利再锁 | 若时间紧，**用下厨房或直接不锁 A3** |

## 锁定前检查清单（下载 APK 后 10 分钟）

```text
[ ] 商店页可打开「隐私政策」
[ ] aapt dump badging 能读出包名/版本
[ ] Jadx 打开后能看到 java 层业务包名（非仅壳）
[ ] 模拟器可安装启动（Android 9–11）
[ ] 记录 SHA-256
[ ] 填入 docs/report/01-samples.md，并在 README 样本表同步
```

Jadx 几乎看不到业务代码 → 视为强加固，**换备选**，不要硬刚。
